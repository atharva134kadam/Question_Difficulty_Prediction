CO4 · prompt engineering

LLM judge vs trained model

Same 90 balanced test questions (30 per level)

Findings

  1. Label anchoring: with v1 zero-shot and chain-of-thought prompts, the 1.5B model answered "Easy" for all 90 questions. It copies the first option of the "Easy|Medium|Hard" template.
  2. Few-shot examples break the anchoring: the model uses all three levels and gets the best F1 and QWK among the LLM strategies.
  3. v2 score-first prompt (our fix): no level words, calibrated anchor questions, level derived from the score in code. This gives the best LLM accuracy.
  4. The trained NLP ensemble still far outperforms every prompt, so the LLM generates and explains, and the NLP model scores and verifies.
